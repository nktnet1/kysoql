`@kysoql/core` is the query-builder package. It owns the typed SOQL builders,
expression helpers, compiler, schema contracts, and the executor interface used by
transport adapters. It also provides compile-only Apex modes for server-side use.

It has no Salesforce HTTP dependency. You can compile SOQL without a connection,
or provide an executor such as [`@kysoql/rest`](/docs/rest) or the optional
[`@kysoql/jsforce`](/docs/jsforce) adapter when you want `.execute()` support.

## Start with a typed query

```ts
import { Kysoql } from "@kysoql/core";
import type { SalesforceSchema } from "./kysoql/salesforce.generated";

const db = new Kysoql<SalesforceSchema>();

const query = db
  .selectFrom("Account")
  .select(["Id", "Name"])
  .where("Name", "like", "Acme%")
  .orderBy("Name")
  .limit(25);

console.log(query.compile().soql);
```

The generated `SalesforceSchema` normally comes from
[`@kysoql/codegen`](/docs/codegen), but core also supports hand-authored schema
types for specialised integrations.

## What belongs to core

- Query creation, selections, filters, relationships, aggregates, and functions.
- Schema capability types and inferred result shapes.
- The `QueryExecutor` contract used by native REST, JSforce, and custom adapters.
- Compile-only Apex-oriented modes for code that runs inside Salesforce.

Kysoql deliberately uses Salesforce terminology rather than inventing a second
query language. Use this page when you know the SOQL feature you need and want
the corresponding typed builder API.

## SOQL SELECT

Salesforce documents a `SELECT` statement as a field list plus optional clauses
such as `WHERE`, `GROUP BY`, and `ORDER BY`. Kysoql exposes those concepts as
builder methods and validates them against generated Describe metadata.

## Compare equivalent queries

Salesforce's reference commonly starts from raw SOQL. The equivalent Kysoql
builder keeps the same concepts visible:

```sql title="Salesforce SOQL"
SELECT Id, Name, BillingCity
FROM Account
WHERE Name LIKE 'A%'
ORDER BY Name DESC NULLS LAST
LIMIT 25
```

```ts title="Kysoql"
import { db } from "./db";

const query = db
  .selectFrom("Account")
  .select(["Id", "Name", "BillingCity"])
  .where("Name", "like", "A%")
  .orderBy("Name", "desc", "last")
  .limit(25);

query.compile().soql;
```

The builder does not replace Salesforce documentation for server-side limits,
permissions, API-version behaviour, or feature availability. Treat Salesforce's
reference as authoritative for the platform and these docs as authoritative for
Kysoql's typed API.

## Executor contract

Core does not depend on a specific transport. A custom executor implements this
public interface:

```ts
import type {
  AbortableQueryOptions,
  CompiledQuery,
} from "@kysoql/core";

interface ExampleExecutorContract {
  executeQuery<O>(
    query: CompiledQuery<O>,
    options?: AbortableQueryOptions,
  ): Promise<readonly O[]>;
  executeAllQuery?<O>(
    query: CompiledQuery<O>,
    options?: AbortableQueryOptions,
  ): Promise<readonly O[]>;
  executeCountQuery?(
    query: CompiledQuery<number>,
    options?: AbortableQueryOptions,
  ): Promise<number>;
  executeAllCountQuery?(
    query: CompiledQuery<number>,
    options?: AbortableQueryOptions,
  ): Promise<number>;
}
```

Only `executeQuery` is required. The builder checks optional capabilities and
throws when a requested mode is unsupported; it does not silently fall back
from QueryAll to ordinary execution or reinterpret row arrays as counts.
Executable builders forward the optional `AbortableQueryOptions` object, so a
custom executor should honour `signal` when it can stop or abandon work safely.

A transport implementation is responsible for authentication, sending SOQL,
validating untrusted responses, pagination policy, errors, and returning the
contract's result shape. The generic `O` is erased at runtime. Merely asserting
an arbitrary JSON response as `O[]` does not validate it. Root builder
`.execute()` calls apply Kysoql's field-alias projection after the executor
returns; direct adapter-style executor APIs can use `applyQueryResultAliases`
when they expose compiled-query execution themselves.

## Wrap an existing executor without inventing capabilities

This wrapper records duration without logging tokens or SOQL values. It only
exposes optional methods actually supported by its delegate:

```ts
import type { QueryExecutor } from "@kysoql/core";

export function timedExecutor(
  inner: QueryExecutor,
  observe: (method: string, milliseconds: number) => void,
): QueryExecutor {
  async function timed<T>(method: string, run: () => Promise<T>): Promise<T> {
    const start = performance.now();
    try {
      return await run();
    } finally {
      // A telemetry failure must not replace a query result or original error.
      try {
        observe(method, performance.now() - start);
      } catch {
        // Report telemetry failures through a separate, non-throwing channel.
      }
    }
  }

  const wrapped: QueryExecutor = {
    executeQuery: (query, options) =>
      timed("executeQuery", () => inner.executeQuery(query, options)),
  };
  const executeAllQuery = inner.executeAllQuery?.bind(inner);
  const executeCountQuery = inner.executeCountQuery?.bind(inner);
  const executeAllCountQuery = inner.executeAllCountQuery?.bind(inner);

  if (executeAllQuery) {
    wrapped.executeAllQuery = (query, options) =>
      timed("executeAllQuery", () => executeAllQuery(query, options));
  }
  if (executeCountQuery) {
    wrapped.executeCountQuery = (query, options) =>
      timed("executeCountQuery", () => executeCountQuery(query, options));
  }
  if (executeAllCountQuery) {
    wrapped.executeAllCountQuery = (query, options) =>
      timed("executeAllCountQuery", () => executeAllCountQuery(query, options));
  }
  return wrapped;
}
```

Supply the wrapper as the `executor` option on `Kysoql`. Preserving the delegate's
`this` binding is important when adapting class-based executors.

## A complete offline adapter test

This is a test double for exactly one query, not an executor that returns valid
results for arbitrary queries. It exercises the native REST adapter without
credentials or network calls:

```ts
import assert from "node:assert/strict";
import { Kysoql } from "@kysoql/core";
import { createRestExecutor } from "@kysoql/rest";
import type { SalesforceSchema } from "./kysoql/salesforce.generated";

const fetch: typeof globalThis.fetch = async (input, options) => {
  const url = new URL(String(input));
  assert.equal(url.pathname, "/services/data/v65.0/query");
  assert.equal(url.searchParams.get("q"), "SELECT Id, Name FROM Account LIMIT 1");
  assert.equal(options?.method, "GET");
  return Response.json({
    done: true,
    totalSize: 1,
    records: [{ Id: "001000000000001AAA", Name: "Example account" }],
  });
};

const db = new Kysoql<SalesforceSchema>({
  executor: createRestExecutor({
    instanceUrl: "https://example.my.salesforce.com",
    accessToken: "test-only-token",
    fetch,
  }),
});
const rows = await db.selectFrom("Account").select(["Id", "Name"]).limit(1).execute();
assert.equal(rows[0]?.Name, "Example account");
```

Add tests for multi-page responses, incomplete responses without a locator,
scalar count envelopes, QueryAll options, and propagated transport failures.
Use compile-only tests to assert expected SOQL, and TypeScript negative tests to
protect rejected field/operator/mode combinations.

## Custom compiler

`QueryCompiler.compileQuery<O>(query, context?)` receives a `SelectQueryNode`
and optional `QueryCompileContext` flags (`apex`, `dynamicApex`) and returns a
`CompiledQuery<O>`. `DefaultQueryCompiler` is the public default implementation.

Replacing it is an advanced extension point, not a raw-SOQL shortcut. A custom
compiler must preserve escaping and context/structural validation; otherwise it
can remove guarantees described elsewhere in these docs. Operation-node exports
from core are primarily types for inspection, not public runtime constructors.

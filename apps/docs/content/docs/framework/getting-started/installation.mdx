## Requirements

Kysoql is ESM-only. The current packages require **Node.js `>=26.0.0 <27`**.

## Install

For the standard Kysoql setup with schema generation, JWT authentication, and
native Salesforce REST execution, install these packages:

<Tabs items={["npm", "yarn", "pnpm", "bun"]} defaultIndex={2}>
  <Tab value="npm">

```bash
npm install @kysoql/core @kysoql/rest @kysoql/auth
npm install --save-dev @kysoql/codegen
```

  </Tab>
  <Tab value="yarn">

```bash
yarn add @kysoql/core @kysoql/rest @kysoql/auth
yarn add --dev @kysoql/codegen
```

  </Tab>
  <Tab value="pnpm">

```bash
pnpm add @kysoql/core @kysoql/rest @kysoql/auth
pnpm add -D @kysoql/codegen
```

  </Tab>
  <Tab value="bun">

```bash
bun add @kysoql/core @kysoql/rest @kysoql/auth
bun add --dev @kysoql/codegen
```

  </Tab>
</Tabs>

`@kysoql/core` provides the query builder, `@kysoql/rest` executes queries
through Salesforce REST, `@kysoql/auth` obtains and renews Salesforce sessions,
and `@kysoql/codegen` generates the schema used for query/result typing.

If you only need to compile SOQL, install `@kysoql/core`. Add
`@kysoql/codegen` when you want generated Salesforce schema types. Install
`@kysoql/jsforce` and `jsforce` only when you specifically want the
[JSforce adapter](/docs/jsforce).

`@kysoql/rest` is the native Salesforce transport for Kysoql. It implements the
core executor contract with `fetch`, so applications can run ordinary Query,
QueryAll, scalar counts, and paginated queries without installing JSforce.

## Connect it to core

```ts
import { Kysoql } from "@kysoql/core";
import { createRestExecutor } from "@kysoql/rest";
import type { SalesforceSchema } from "./kysoql/salesforce.generated";

export function createDatabase(instanceUrl: string, accessToken: string) {
  return new Kysoql<SalesforceSchema>({
    executor: createRestExecutor({ instanceUrl, accessToken }),
  });
}
```

The adapter follows root and selected relationship continuation pages automatically,
including deeply nested parent-to-child subqueries, while respecting each compiled
`LIMIT`. It also handles QueryAll continuation, structured Salesforce errors,
cancellation, request deadlines, bounded collection, and async root-page/record
iteration.

---
title: "Introduction"
description: "Generate schema-aware Kysoql types from Salesforce Describe metadata."
---

`@kysoql/codegen` turns Salesforce Describe metadata into the schema types used by
`@kysoql/core`. It includes the `kysoql generate` CLI as well as programmatic
Describe, loading, filtering, and rendering APIs.

Native REST is used for CLI metadata requests, so code generation does not require
JSforce.

## Configure generation

```ts title="kysoql.config.ts"
import { defineConfig } from "@kysoql/codegen";

export default defineConfig({
  objects: ["Account", "Contact", "User"],
  schemaName: "SalesforceSchema",
});
```

With a `src` directory, that writes `src/kysoql/salesforce.generated.ts` by
default. Set `output` when the application needs a different location. You can
keep every described field or define exact per-object include/exclude rules when
an application intentionally exposes a smaller query surface.

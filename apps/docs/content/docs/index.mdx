---
title: "Kysoql"
description: "A type-safe Salesforce SOQL query builder for TypeScript."
---

Kysoql builds Salesforce Object Query Language (SOQL) queries using your org's
Describe metadata. Select fields, filter records, traverse relationships, and
build aggregate reports with inferred TypeScript results.

It is a query builder, not an ORM: it does not create records, update records,
manage transactions, or generate Salesforce objects. You can compile queries
without a connection, execute API queries through an adapter, or produce
compile-only SOQL for an Apex caller.

## Start here

[Install the packages](/docs/getting-started/installation), then follow the
[quickstart](/docs/getting-started/quickstart) to generate an org-specific schema,
compile a query, and execute it through native REST, without JSforce.

```ts
import { Kysoql } from "@kysoql/core";
import type { SalesforceSchema } from "./salesforce.generated";

const db = new Kysoql<SalesforceSchema>();

const query = db
  .selectFrom("Account")
  .select(["Id", "Name"])
  .where("Name", "like", "Acme%")
  .orderBy("Name")
  .limit(25);

console.log(query.compile().soql);
// SELECT Id, Name FROM Account WHERE Name LIKE 'Acme%'
// ORDER BY Name LIMIT 25
```

This example only compiles. Calling `execute()` requires an
[executor](/docs/guides/execution).

## Packages

| Package | Purpose |
| --- | --- |
| `@kysoql/core` | Query builders, schema types, SOQL compiler, and executor contract. |
| `@kysoql/rest` | Native query/QueryAll execution, counts, pagination, OAuth helpers, and cancellation. |
| `@kysoql/jsforce` | Optional adapter for applications that already use JSforce. |
| `@kysoql/codegen` | Describe-driven schema generation and the `kysoql` CLI. |

These docs use the repository's existing `@kysoql` scope. The supplied package
manifests are version `0.0.0`; installation examples assume the packages have
been published to your configured registry. They do not imply a public release
is available. See [local workspace use](/docs/getting-started/installation#use-the-workspace-before-publication).

## What validation does and does not guarantee

Generated types constrain object names, field names, relationship paths, values,
and capabilities such as `filterable` or `groupable`. Builder and compiler
validation also reject many invalid clause combinations. Neither replaces the
Salesforce server: org permissions, API versions, enabled features, current
metadata, query selectivity, and runtime governor limits still apply.

All guides describe the API in this repository snapshot. Beta and pilot features
are [explicitly separated](/docs/advanced/experimental), not presented as ordinary
production features. There is no arbitrary raw-SOQL escape hatch in the public
builder API.
